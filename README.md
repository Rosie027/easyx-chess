# EasyX 国际象棋

一个使用 C/C++ 与 EasyX 编写的 Windows 本地双人国际象棋图形化原型。项目包含启动动画、阵营与视角选择、棋盘交互、基础走法验证、将军/将死判断、简化棋谱，以及求和、认输、重开等界面流程。

> 当前状态：课程阶段性作品。核心交互已经整合，但并不是完整、严格的国际象棋规则引擎。

## 功能

- 8×8 棋盘与完整棋子初始布局；
- 白方/黑方视角切换；
- 鼠标选择、移动、吃子与选中高亮；
- 王、后、车、象、马、兵的基础走法生成；
- 过滤会使己方王被将军的走法；
- 初步将军和将死检测；
- 简化棋谱与回合显示；
- 求和、认输、重新开始和退出界面；
- 100 帧启动动画。

## 目录结构

```text
easyx-chess/
├─ include/chess.h                 # 数据结构、常量和函数声明
├─ src/
│  ├─ main.cpp                     # 窗口初始化与事件循环
│  ├─ move.cpp                     # 走法生成、合法性与移动执行

│  └─ ui.cpp                       # 资源加载、绘制、按钮与棋盘交互
├─ assets/                         # 棋子、页面、按钮和启动动画帧
├─ experiments/notation-prototype/ # 早期独立棋谱模块
├─ docs/development-notes/         # 设计和开发过程记录
└─ examples/test_game.txt          # 早期棋谱测试数据
```

## 实现逻辑

1. `main.cpp` 初始化 EasyX 窗口、资源与启动动画，并进入鼠标消息循环。
2. `ui.cpp` 将屏幕坐标转换为棋盘坐标，维护页面状态、棋子选择与绘制。
3. `move.cpp` 先为当前玩家生成伪合法走法，再模拟每一步并调用 `isInCheck`，过滤会暴露己方王的走法。
4. 移动成功后更新棋盘、生成简化棋谱，并检查对方是否被将死。

## 构建与运行

运行环境：Windows、支持 C++17 的 Visual Studio、EasyX 图形库。

```powershell
cmake -S . -B build -DEASYX_INCLUDE_DIR="你的 EasyX include 目录" -DEASYX_LIBRARY="你的 EasyX .lib 文件"
cmake --build build --config Release
```

程序依赖相对路径 `assets/`，请从仓库根目录运行生成的程序。若使用 Visual Studio 工程，也需要将工作目录设置为仓库根目录。

公开整理时已经使用 Visual Studio 2022、EasyX x64 库完成编译和链接验证。由于图形程序需要交互窗口，本轮没有自动执行完整对局测试。

## 已知限制

- 未实现王车易位、吃过路兵和兵升变；
- `isStalemate` 仍未实现，不能完整判断逼和；
- 当前代码保留“吃掉王即可结束”的兜底逻辑，与标准规则不完全一致；
- 棋谱只记录棋子与目标格，不是完整 SAN，缺少吃子、将军、升变和同类棋子消歧；
- 素材许可尚需最终确认，公开发布前请补充来源或替换为自制/明确授权素材。
