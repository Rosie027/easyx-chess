# 代码结构

## 页面与资源

`ui.cpp` 管理启动页、阵营选择页、棋盘页和临时弹窗。`Resource` 结构体集中保存 EasyX 图片对象，按钮通过 `Button` 数组注册并按当前页面响应。

## 棋盘状态

棋盘使用 `ChessPiece board[8][8]` 表示。每个棋子记录类型、颜色和是否移动过。当前玩家、选中格、最近一步与页面状态作为共享状态保存。

## 走法验证

`generatePseudoMoves` 根据不同棋子的移动规则生成候选集合。`generateLegalMoves` 临时执行候选走法，通过 `isInCheck` 判断己方王是否暴露，再恢复棋盘。合法走法由 `isValidMove` 查询。

## 后续重构方向

- 用 `GameState` 封装棋盘和回合状态，减少全局变量；
- 将绘制与规则逻辑完全分离；
- 为每类棋子补充单元测试；
- 实现王车易位、升变、吃过路兵、逼和与完整 SAN；
- 使用资源清单统一管理图片来源和许可。
