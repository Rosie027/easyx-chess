## ✅ 一、核心目标澄清：什么是“标准棋谱输出”？

在国际象棋中，“标准棋谱”通常指 **代数记谱法（Algebraic Notation）**，例如：

```
1. e4 e5  
2. Nf3 Nc6  
3. Bb5 a6
```

你的程序需要能**根据一局棋的走子过程，生成这样的文本记录**。

> 📌 注意：你**不需要实现 AI 或走子逻辑**，只需**记录合法走法并按规则转为标准符号**。

## ✅ 二、必须学习的国际象棋知识（最小集合）

### 1. **棋盘坐标系统（最重要！）**

- 棋盘是 **8×8** 的格子。
- **列（文件）用 a–h 表示**（从白方左侧开始：a, b, c, ..., h）
- **行（横线）用 1–8 表示**（白方底线是第 1 行，黑方是第 8 行）
- 每个格子用 **“字母+数字”** 表示，如 `e4`、`g1`、`h8`

> 💡 示例：白方国王初始位置是 `e1`，黑方皇后在 `d8`。

✅ **你需要做的**：在 C 程序中用 `char board[8][8]` 表示棋盘，但输出时**将数组索引映射为 a1–h8 坐标**：

```
c
// board[0][0] 是 a8（黑方左上角）？还是 a1（白方左下角）？
// 通常：board[7][0] = a1, board[0][7] = h8
// 需统一约定！
```

### 2. **六种棋子的英文缩写（用于记谱）**



| 棋子 | 英文名 | 记谱符号       | 说明                              |
| ---- | ------ | -------------- | --------------------------------- |
| 王   | King   | **K**          |                                   |
| 后   | Queen  | **Q**          |                                   |
| 车   | Rook   | **R**          |                                   |
| 象   | Bishop | **B**          |                                   |
| 马   | Knight | **N**          | ⚠️ 不是 K（K 已被王占用）          |
| 兵   | Pawn   | **（无字母）** | 兵的走法**只写目标格子**，如 `e4` |

> ✅ 示例：
>
> - 马从 g1 走到 f3 → **`Nf3`**
> - 兵从 e2 走到 e4 → **`e4`**
> - 象从 c1 走到 b2 → **`Bb2`**

### 3. **基本走子表示规则（如何生成记谱字符串）**



| 情况               | 记谱格式                                          | 示例                   |
| ------------------ | ------------------------------------------------- | ---------------------- |
| **普通走子**       | `[棋子符号][目标格]`                              | `Nf3`, `Bc4`           |
| **兵的走子**       | `[目标格]`                                        | `e4`, `d5`             |
| **吃子**           | `[棋子符号][吃子格][x][目标格]`（兵需标明出发列） | `exd5`, `Nxe5`, `Rxd8` |
| **将军**           | 在末尾加 `+`                                      | `Qh5+`                 |
| **将死**           | 在末尾加 `#`                                      | `Qh5#`                 |
| **王车易位（短）** | `O-O`                                             |                        |
| **王车易位（长）** | `O-O-O`                                           |                        |

> ⚠️ 注意：**兵吃子时必须写出出发列**，如 `exd5`（e 列的兵吃掉 d5 的子）

### 4. **特殊规则（仅需知道记谱形式，不必深究规则）**



| 规则                       | 记谱表示                                                     | 说明                    |
| -------------------------- | ------------------------------------------------------------ | ----------------------- |
| **吃过路兵（en passant）** | 和普通吃子一样，如 `exd6 e.p.`（但标准记谱常省略 e.p.，只写 `exd6`） | 你可先按普通吃子处理    |
| **升变（Promotion）**      | `[目标格]=[新棋子]`                                          | 如 `e8=Q`（兵升变为后） |
| **回合编号**               | 每行以 `1.`, `2.`, `3.` ... 开头，白方在前，黑方在后         | `1. e4 e5`              |

## ✅ 三、在 C 程序中如何实现“棋谱输出”？

你不需要懂棋，但需设计数据结构记录每一步，并按规则转为字符串。

### 步骤 1：定义走子结构

```
c
typedef struct {
    int from_row, from_col;   // 起始位置（数组索引）
    int to_row, to_col;       // 目标位置
    char piece;               // 走的棋子（'P','R','N','B','Q','K'）
    char captured;            // 被吃棋子（0 表示无）
    bool is_castling;         // 是否王车易位
    char promotion;           // 升变棋子（0 表示无）
    bool is_check;            // 是否将军
    bool is_checkmate;        // 是否将死
} Move;
```

### 步骤 2：写一个函数，将 Move 转为标准记谱

```
c
void move_to_algebraic(Move m, char* output) {
    // 1. 特殊情况：王车易位
    if (m.is_castling) {
        if (m.to_col == 6) strcpy(output, "O-O");
        else strcpy(output, "O-O-O");
        return;
    }

    // 2. 普通走子
    char notation[10] = "";

    // 兵不写符号，其他写
    if (m.piece != 'P') {
        strncat(notation, &m.piece, 1);  // 但需转为 'N' 而非 'n'
    }

    // 3. 吃子？
    if (m.captured != 0) {
        if (m.piece == 'P') {
            // 兵吃子：加出发列
            char file = 'a' + m.from_col;
            strncat(notation, &file, 1);
        }
        strcat(notation, "x");
    }

    // 4. 目标格子
    char target[3];
    target[0] = 'a' + m.to_col;
    target[1] = '1' + m.to_row;  // 注意：需根据你的 board 坐标系调整！
    target[2] = '\0';
    strcat(notation, target);

    // 5. 升变？
    if (m.promotion) {
        char promo[3] = "=?";
        promo[1] = m.promotion; // 'Q', 'R' 等
        strcat(notation, promo);
    }

    // 6. 将军/将死
    if (m.is_checkmate) strcat(notation, "#");
    else if (m.is_check) strcat(notation, "+");

    strcpy(output, notation);
}
```

> 🔑 关键：**你的棋盘坐标系必须和 a1–h8 对应**！
> 建议：`board[7][0] = a1`（白方左下角），`board[0][7] = h8`（黑方右上角）
