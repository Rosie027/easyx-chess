## 国际象棋项目模块化工作流方案

### 项目分块与阶段划分

#### ***阶段一:核心逻辑实现***(大家现主要需要完成的部分)

**模块1：游戏核心架构**

- **要做什么**：
  - 设计程序整体结构
  
  - 定义数据结构和接口
  
  - **实现游戏主循环**
  
    

**模块2：棋盘与棋子管理**==不同棋子单独作为函数编写==

- **要做什么**：
  - 实现棋盘初始化
  - 管理棋子位置状态
  - 处理棋子移动基础操作

**模块3：走法验证系统**==判断走法函数==

- **要做什么**：
  - 实现每种棋子的移动规则
  - 验证走法合法性
  - 处理特殊规则（王车易位、吃过路兵、兵升变）
  - 防止自将走法

**模块4：胜负判断**==胜负判断函数==

- **要做什么**：
  - 检测将军状态
  - 判断将死和困毙
  - 处理和棋条件
  - 评估游戏终局
  
  

#### **阶段二：用户交互开发 **
**目标**：创建用户界面

**模块5：控制台界面**
- **要做什么**：
  - 设计棋盘显示格式
  - 实现游戏信息展示
  - 添加游戏菜单系统

### 完整工作流程

```
建立基础框架
├─ 核心架构组：设计数据结构，搭建程序骨架
├─ 棋盘管理组：实现基础棋盘操作
└─ 测试组：建立测试环境，编写基础测试用例

实现核心规则  
├─ 走法验证组：逐个实现棋子移动规则
├─ 胜负判断组：实现将军和将死检测
├─ UI组：开发基础棋盘显示
└─ 测试组：为每个新功能添加测试

完善用户体验
├─ UI组：优化界面，添加游戏流程
├─ 规则组：完善特殊规则处理
└─ 测试组：进行全面测试，修复bug

（可选）：扩展功能
├─ 全体：根据时间选择添加中国象棋或图形界面
└─ 测试组：确保扩展功能稳定性
```

### 各模块详细工作说明

#### 模块1：游戏核心架构
**具体任务清单**：
- [ ] 定义结构体1（类型、颜色、位置）
- [ ] 定义结构体2（棋盘、当前玩家、游戏状态）
- [ ] 编写main()函数和游戏主循环
- [ ] 设计模块间接口函数
- [ ] 实现游戏初始化函数
- [ ] 创建模块协调机制



#### 模块2：棋盘与棋子管理
**具体任务清单**：
- [ ] 实现棋盘初始化函数

- [ ] ==编写棋子放置和移动函数==

- [ ] 创建棋盘状态查询函数

- [ ] 实现走法历史记录

- [ ] 添加棋盘重置功能

  

#### 模块3：走法验证系统
**具体任务清单**：
- [ ] 实现兵的走法验证（包括首次两格、吃子、升变）
- [ ] 实现车、象、后的直线移动验证
- [ ] 实现马的L形移动验证
- [ ] 实现王的移动验证（包括王车易位）
- [ ] 添加吃过路兵规则
- [ ] 防止移动后自将的验证





#### 模块4：胜负判断引擎
**具体任务清单**：
- [ ] 检测将军状态
- [ ] 判断将死条件（无合法走法且被将军）
- [ ] 判断困毙条件（无合法走法但未被将军）
- [ ] 处理和棋（三次重复、50步规则等）
- [ ] 实现游戏结束检测





#### 模块5：控制台界面
**具体任务清单**：
- [ ] 设计显示棋盘
- [ ] 实现棋子符号显示（如♜♞♝等）
- [ ] 添加游戏状态信息显示
- [ ] 实现菜单系统(开始,结束,选择)
